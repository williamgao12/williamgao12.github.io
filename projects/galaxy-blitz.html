Galaxy Blitz

A 2D platform game built in Python.

  • Python
  • Game physics
WhenSpring 2025, Carnegie Mellon University
My roleCo-developer
ToolsPython

What I did

  • Built sprite animations, game physics, and player and environment interactions.
  • Handled resolution mapping and core game logic.

How it works

I worked with one teammate to develop the game. The game is built with CMU Graphics, Carnegie Mellon University's own Python graphics library, which let us take in user input and update objects on the screen. I mainly worked on the minion battle screen, where I spent a lot of time implementing object collision and game physics, and making sure each sequence transitioned smoothly into the next.

What went wrong and how I fixed it

One issue we ran into was combining my partner's code with mine. To fix it, we wrote functions that let our separate code files connect smoothly, and we both agreed to build our parts around them. We also added comments throughout, which made our code much more readable.
